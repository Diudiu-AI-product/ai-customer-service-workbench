# 评测目录说明

这个目录用于放置智能客服原型的轻量评测材料。

当前版本先提供最小骨架，方便后续继续扩展。

## 目录结构

```text
eval/
├─ README.md
├─ sample_dataset.jsonl
└─ run_eval.py
```

## 设计目标

这个目录主要解决两个问题：

1. 让“评测框架”不只停留在文档里
2. 为后续增加自动评测留下清晰入口

## 当前包含内容

### `sample_dataset.jsonl`

一个小型样例数据集，用来演示评测样本应该长什么样。

### `run_eval.py`

一个非常轻量的脚本骨架，用来读取样本数据并输出基础统计。它暂时不直接调用主程序，而是先把数据结构和评测入口固定下来。

## 后续可以怎么扩展

- 增加更多已标注样本
- 接入真实的意图路由评测
- 加入回复质量人工打分
- 加入失败案例分类统计
- 接入自动生成评测报告
